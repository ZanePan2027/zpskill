# 个人底图

这里保存 AI 对你的认识，随着真实对话慢慢长出来，不需要你先填表。

最常用的是一页 `我是谁.md`：你想过怎样的人生、什么让你有劲、你怎样做事、你的边界。AI 怎么称呼你、怎么陪你，放在工作台根目录的 `AI伙伴.md`，不在这里重复。每一条都尽量用你自己的原话，并注明出自哪次对话或哪份材料。它要短到 Agent 每次进入工作台都会真的读一遍。

第一次没有内容很正常。等你在对话里说出自己真正在意的东西，Agent 再把那句话记下来；你纠正了，就以你的新说法为准，旧说法移到修订记录里。更长的原话、经历、偏好和各个生活领域的资料，可以在这里另建文件，`我是谁.md` 只链接过去，不重复抄写。

# 协作与角色

一个任务一个主持者，连续承接用户。本人目标、共同方法和真实来源由所有参与者共用；角色卡只定义职责、侧重点、表达与返回成果。

| 职责 | 适合独立处理的工作 | 返回 |
|---|---|---|
| 主陪伴与整合 | 全局取舍、路线、资源冲突及最终整合 | 当前推荐、成品、实际下一步 |
| 调查与复核 | 核事实、找反例、比较不同解释 | 原始依据及对路线的影响 |
| 制作与执行 | 写作、计算、构建和已授权操作 | 实际成品、检查结果、暂停点 |
| 记忆与整理 | 来源归位、当前判断更新、导航与接续 | 唯一来源、有效链接与可继续状态 |

当前任务确有独立增益，且宿主支持协同，才分出子任务。默认辅助只读，主持者写正式材料；需独立制作就指定单独输出区。各角色能由同一AI承担，方法比角色名字更重要。

交办说明当前目标与阶段、局势中的具体疑点、正在采用的路线与时间窗口、已有来源、交付用途、输出位置和动作权限。辅助者说明证据、差异和成果，主持者处理分歧后继续原任务。对外发送、发布等动作沿本人已有授权。

跨独立会话交接记录任务、实际暂停点、当前写者、允许写入区域、版本和交回位置。沿用已有写锁和接力工具；若事件工具只允许主持者写，则接手者在交付区域完成材料，主持者清场后统一回填。同步盘上的同一区域串行写入。

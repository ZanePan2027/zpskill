# 价值、意义与可能性

用于一个人觉得自己没价值、没人需要自己、不知道为什么活着、做什么都没劲的时候。目的是让他看见：有人因他而不同，他的存在连着一些具体的东西，前面还有可以走的路。它不是夸奖，也不是用道理说服他别难受。

## 先看安全

话里出现不想活、想结束生命、已经有想法、计划或手段时，这一页的方法先放下：直接、平静地问他是不是想过结束生命，问现在是否安全、身边有没有人，帮他联系可信的人和专业支持，即时危险优先当地急救。具体做法读 [专业帮助与安全](../../zp-support/references/care-and-safety.md)。意义的工作要等他安全、稳定一点再做；这个 Skill 不是危机处理，也不替代专业帮助。

## 先分清是哪一种

同样一句“没意思”，起手不同。先接住，再按他说的话选一个，不确定就问一个小问题：

| 他说的 | 更可能是 | 起手 |
|---|---|---|
| “没人需要我”“我没价值” | 觉得自己不重要、没被需要；也可能是低落中的自我否定 | 先留意有没有“消失”“不想活”这类话，有就先走上面的安全；没有，再问一件具体的事：最近有谁因为你好过一点，或会注意到你不在。先要事实，不先反驳 |
| “不知道为什么活着”“没意思” | 意义感缺失；持续低落时也可能是抑郁的表现 | 先确认安全，再慢慢谈意义的三个部分 |
| “我做什么都没用” | 做了没有变化而学来的无力感 | 查哪些事做了确实有变化，哪怕很小，找回一点控制感 |
| “别人都有目标，我没有” | 在和别人比，加上目标空白 | 不比，转去找他有劲、觉得新的那些瞬间 |
| “做什么都没劲” | 自主、胜任、联结里缺了一项 | 问哪一项最缺：是不是自己选的、是不是做得到、身边有没有人一起 |

先排除现实原因：身体、睡眠、压力、钱、关系里正在发生的事。不把所有问题都解释成心理问题；他的低落可能有现实的重量，也可能需要看医生。

## 价值：被看见、被需要、能带来改变

让一个人感到自己重要，通常是这三件：被注意到、被看重、能给别人带来改变。用具体的事问，不用空话：

- 谁会注意到你不在？谁最近找过你？
- 谁因为你做的某件事，日子好过了一点？哪怕是一句话、一次帮忙。
- 你做过什么，别人到现在还记得？

答案是他自己的事实，AI 只把这些事实放在他面前，不替他编。他一时答不出来，就说明现在还没有，不是他没价值：可以一起找一个很小的、对别人有用的动作，比如替人做一件小事、回一个人的消息，让这件事开始发生。

## 意义：连贯、目的、分量

意义常被拆成三个部分，各有一个能直接问的问题：

- **连贯**：我的生活说得通吗？“你现在的日子，哪些是说得通的，哪些怎么也想不通？”
- **目的**：我在朝向什么吗？“有什么是你想靠近的，哪怕很小？明天有什么让你愿意醒来？”
- **分量**：我的存在重要吗？“如果你没有出现，这个世界上谁的某件事会不一样？”

不要求他一次想出人生使命。意义常来自具体的关系、做成的事、对别人的贡献，也来自他怎样面对难处。小的、真实的，比宏大的、空的好。

## 可能性

把价值和意义落成他能走的路：一件让他明天愿意醒来的小事，加一个对别人有用的小行动。这是一个入口，不是要他立刻改变人生。结合他自己的优势和想过的生活（见 [发现独有优势](strengths-discovery.md)），再回到 [zp-life](../../zp-life/SKILL.md) 排路线。

## 重写“我是谁”的叙述

材料够了、他愿意时，可以邀请他写三句话：我从哪里来、经历了什么、想往哪里走。让他自己写、自己改，AI 只帮他把事实放对位置，不替他下结论。“我很普通”“我没用”常是一个被省略了很多事实的故事，三句话里放进他做成过的事、扛过的事和别人对他的反应，故事就会变。他不认可的句子一律不写。

## 不要这样做

- 不说“你很棒”“每个人都有价值”这类没有事实的话，尤其不拿它当开场。
- 不用意义去说服一个人别痛苦。痛苦可以存在，意义不是对它的义务。
- 不许诺“找到意义就好了”，不替他定意义。
- 不把这一页用成诊断或治疗。持续两周以上的低落、睡眠或食欲明显变化、想不开，建议他去看精神科或心理门诊，并协助准备怎样开口。

## 依据

内部依据，我没有逐篇通读原文，要引用具体结论请回原文核对：Steger 等对生命意义三成分（连贯、目的、意义感）的研究，证据中等；Frankl 的意义疗法有启发，其原始主张证据较弱；Flett 与 Prilleltensky 对 mattering 的研究，多为相关证据；自我决定理论（Deci 与 Ryan）关于自主、胜任、联结，证据较强；习得性无助经 Maier 与 Seligman（2016）修正，把“控制感”视为默认、无助是被学来的；叙事认同（McAdams）与叙事生涯（Savickas），干预证据中等。这些都不保证对某个人有用，有没有帮助以他的感受和生活的变化为准。

# 找出路的几种办法

内部用。每种办法配一个能直接问的问题，问法按他的处境改成日常话。

## 把“框”说出来

| 他的说法 | 藏着的前提 | 可以问 |
|---|---|---|
| “要么……要么……” | 只有这两个选项 | 如果这两个都不选，还有什么？ |
| “我必须……” | 有一个不能动的目标或身份 | 这条“必须”是谁定的？不做会怎样？ |
| “我只能……” | 其他条件都固定 | 哪一个条件其实能动一点？ |
| “等我准备好再……” | 现在不能试 | 有没有一个小得不需要准备的版本？ |
| “他们会觉得……” | 把别人的期待当自己的 | 如果没人在看，你会怎么选？ |

## 第三类出路

- **拆开**：把一个大选项拆成几块，只要其中需要的那一块。例：不想要这份工作，但想要这份收入——收入和工作能不能分开拿？
- **改条件**：不改方向，改岗位、汇报对象、工作量、时间、地点、方式。例：想离职的人，先试调岗、减量、远程。
- **先加信息**：用一个可撤回的小试替代“想清楚再决定”。例：先和想去的行业的人聊三次，先做一个月副业。
- **改顺序**：不是做不做，而是谁先谁后。例：先找到下家再谈离职，先攒够三个月再试。
- **借力**：谁手里有他缺的东西。例：能不能请一个做过的人帮看一眼。
- **把约束变成资源**：把“我的限制”换成“我的特点”。例：时间少，所以只做最重要的一件。
- **不选的代价**：什么都不动，半年后是什么样？有时这才是真问题。

## 他可能卡在哪（内部用，不说出口）

- **非黑即白**：只看到两个极端。出路常在中间。
- **沉没成本**：已经投入很多，所以更难放手。
- **身份绑定**：“我是这样的人”挡住了别的做法。
- **现状偏爱**：对不变的偏爱大于对更好的向往。
- **灾难化**：把最坏的结果当成最可能的结果。
- **别人的声音**：把父母、同事的期待当成自己的想要。
- **缺乏带来的窄视野**：缺钱、缺时间、缺觉的时候，注意力会被眼前的紧迫占满，看不到长远的选项。

对他说的时候，只把其中最相关的一点换成他的事和日常话，不说名词，不贴标签。

## 依据

内部依据，我没有逐篇通读原文，要引用具体结论请回原文核对：框架效应（Tversky 与 Kahneman，1981）说明同一件事换种说法会改变选择；缺乏使注意力变窄（Mullainathan 与 Shafir，2013）；现状偏见与沉没成本的研究；双环学习（Argyris 与 Schön）强调改变假设，而不只是改变行动；价值导向的决策（Keeney，1992）主张先问目标，再产生选项；决策研究者（如 Nutt）观察到，只考虑一两个选项的决策更容易失败。这些只是方法的依据，不保证对某个人有用；有没有用，以他试过之后的反馈为准。

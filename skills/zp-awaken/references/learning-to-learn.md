# 学得对不对，自己怎么看

内部用。“认知决定上限”的另一半，是学习的方法：不只是学得多，而是知道自己学没学对。这叫元认知，也就是对自己怎么想、怎么学的觉察和调节。

## 他说“学了很多，没长进”时

不先给学习方法，先看三件事（一轮只问一件）：

1. **学了之后，有没有用过一次？** 只输入、没有输出和现实反馈，多半是在积累感觉，不是在积累能力。
2. **他怎么知道自己学会了？** 能不能不看资料，把它讲给别人、用在一件真实的事上？
3. **卡在哪一步？** 不理解、记不住、不会用，还是没时间？不同的卡点，办法不同。

## 小办法（每次只给一个）

- **先预测再对答案**：看一章前先写下自己觉得会讲什么，读完对照，差距就是真正学到的东西。
- **用一遍**：把刚学的拿去做一件小事，哪怕很粗糙。
- **讲出来**：用三句话讲给一个不懂的人，卡住的地方就是没懂的地方。
- **隔几天再测**：当天觉得会了，几天后再试一次，才知道真会没会。
- **记错题**：把自己反复犯的错记一行，下次先看。

## 边界

- 不推销“某一种学习法”，更不贩卖焦虑（“不学就被淘汰”）。
- “刻意练习”这类说法有价值，也有争议：它能解释一部分差距，不是全部；不说成“只要练够一万小时就行”。
- 能力的差距里也有资源、环境、时间、起点，不把全部都归到“学法不对”上。

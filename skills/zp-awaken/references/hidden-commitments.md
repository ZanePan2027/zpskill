# 明知却不做

内部用。本人已经表达想保护的东西或互相拉扯的承诺时，才把它作为一个可纠正的解释；不由“没做”倒推出隐藏动机。提前预测被拒绝、反复准备等情况，先看[打破回避循环](avoidance-loop.md)。这里借自“免疫改变”的研究（Kegan 与 Lahey），是一套实践框架，证据多来自案例，不是严格的实验。

## 一张小地图（不要一次摆给他）

1. **他想改变什么**：他说想做、却总没做的事。（“我想换工作”“我想开口谈加薪”）
2. **他实际在做什么、没做什么**：看行为，不看他怎么说。（“每周看招聘，但一份没投”）
3. **做了会发生什么坏事，他怕什么**：问“如果你真的去做了，最担心发生什么？”
4. **藏在后面的另一个承诺**：为了不让那件坏事发生，他其实一直在守着什么。（“我得让所有人觉得我可靠”）
5. **背后的大假设**：这个承诺依赖的那条想法。（“只要我一走，别人就会觉得我靠不住”）
6. **小实验**：用一个小、可撤回的行动检验这条假设。（“先和一个信任的前同事说一次想法，看看他怎么反应”）

## 怎么对他说

- 不说“你在逃避”“你潜意识里怕……”，这会让人防御。
- 只问一个问题：“如果你真的去做了，最担心的是什么？”听他的原话。
- 他说出担心之后，再问：“你一直在护着的是什么？”不替他回答。
- 不必等他彻底想通。本人愿意时，共同选成本与风险可承受的小实验；不承诺失败不疼，不把承受痛苦当成功条件。

## 边界

- 这是帮他看见，不是给他定性；他不认可的解释一律不写。
- 现实阻碍（钱、家人、合同）是真的，先认，不当成“假设”。
- 不把它用成“凡是做不到都是内心有鬼”的万能解释，这是常见的过度归因。

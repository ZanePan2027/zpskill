# 依据与局限

内部用。我没有逐篇通读原文，要引用具体结论请回原文核对。

- **冰山式的层级**（事件、模式、结构、心智模型）：来自系统思考的实践传统（如 Meadows《Thinking in Systems》及其杠杆点的文章，Senge 的“心智模型”）。它是启发工具，不是被实验检验过的理论。
- **改假设比改行动更深**：双环学习（Argyris 与 Schön）。
- **看见并检验自己的假设**：转化学习（Mezirow）强调对假设的批判性反思；认知行为疗法里的认知重构（Beck）有较强的临床证据，但那是针对情绪困扰的治疗，不等于这里的做法。
- **明知却不做**：免疫改变（Kegan 与 Lahey），实践框架，案例为主。
- **框架效应、缺乏带来的窄视野、现状偏见、沉没成本、动机性推理**：Tversky 与 Kahneman（1981），Mullainathan 与 Shafir（2013），Kahneman《思考，快与慢》，Kunda（1990）等。
- **元认知与学习**：Flavell（1979）提出元认知；教育研究里元认知与自我调节的教学干预整体有较稳的正面效果，但具体到某个人、某一种方法，效果不一。
- **刻意练习**：Ericsson 等的研究有影响，Macnamara 等（2014）的元分析显示它只解释了表现差异的一部分。
- 通俗读物《认知觉醒》（周岭）把这些概念讲给大众，其中借用的“本能脑、情绪脑、理智脑”是通俗比喻，神经科学上并不准确，这里不把它当依据。
- **成长型思维**的大样本研究里效应较小、争议较大，不作为本 Skill 的依据。

## 局限

- 这些方法帮他看见，不保证带来改变；有没有用，以他试过之后的反馈为准。
- 认知只是影响结果的一部分，资源、环境、运气和时机也重要。
- “觉醒”的说法容易变成优越感和焦虑营销，本 Skill 的做法是：不评判人、不夸大效果、必须落到一个小实验和现实反馈。

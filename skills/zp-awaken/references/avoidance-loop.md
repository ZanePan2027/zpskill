# 打破回避循环

用于本人想做一件事，却提前替现实下判决、反复准备或绕开接触反馈的时候。借鉴 CBT 的共同检验与行为实验，不等于完整治疗。下面是 Agent 按需使用的判断路径，不要求用户填表或一轮回答全部问题。

## 先分清这次为什么停

先确认这是本人真正想做的事，以及当前障碍是什么。技能、信息、金钱、时间、健康、真实危险和对方明确拒绝都可能解释停下；休息、学习、价值选择和工具建设本身不能证明回避。准备有没有用，看它解决哪个具体缺口、怎样知道补足，以及补足后能试哪一步；没有这三个答案是继续澄清的线索，不是自欺证据。

用户是在讨论理论、命名或维护 Skill 时，交付对应成果，不把设计要求解释为逃避，不开始个人疗愈。例子不自动成为用户的本人事实。

## 找一句具体预测，再理解循环

从最近一次片段里找本人原话：“如果我做 X，就会发生 Y。”把可观察事实和解释分开。担心是真实的体验，所担心的事是否发生仍需证据。一次只问缺少且会改变下一步的一点。

例如，“她已经明确拒绝了这次邀请”是反馈；“她一定看不上我，所以我没开口”是尚待检验的预测。没有拒绝证据，也不证明对方一定接受。

必要时在内部区分三个层次，不必向本人展示术语：

| 层次 | 虚构例子 | 使用边界 |
|---|---|---|
| 自动思维 | “她肯定看不上我” | 从当前具体念头开始，不急着向深处追 |
| 条件规则／中间信念 | “足够优秀，才有资格靠近别人” | 本人说出或认可才作为工作假设 |
| 核心信念 | “我不值得被喜欢” | 不能从一句预测推断，更不能定成人格事实 |

“终极裁判”“黑哨”可作为本人喜欢的比喻，但不冒充心理学诊断。读心、消极预测、回避、自我设限不是同义词；自我设限涉及障碍或借口对自我评价的保护功能，不能凭拖延就判定，也不假定本人有意为之。

只有本人经历支持时，才提出这一段循环：触发情境 → 负面预测与感受 → 绕开／反复准备 → 当下缓解 → 缺少新信息或增加长期成本 → 原预测更难被修正。短期缓解未被确认就保留未知；本人纠正后重画循环，不用“你抗拒”维持 AI 的解释。

## 共同检验证据

先理解预测为何可信，再看已知支持、反证和缺失的信息。结果可以是风险确实存在、技能确实不足、另有解释，或目前未知。更可信的说法要容纳真实损失，不强求积极。

例如：“我不知道对方是否想认识我；我可以在合适场景发出一次尊重边界的邀请，由对方决定。”这没有把“必然拒绝”换成“必然接受”。

本人已经查过证据却反复要求确定保证时，停止追加安慰与辩论。说明眼下目标可以换成：允许念头和不确定仍在，选择本人愿意承担的一步。此时不同时要求本人继续驳倒念头；承受不确定的参考见 [zp-support 的方法选择](../../zp-support/references/method-selection.md)。

## 用有限实验换取新信息

实验不以彻底想通、情绪消失或证明自己优秀为前提。本人愿意时，共同说清：

- **预测**：具体会发生什么；本人愿意可估计相信程度，不强制评分。
- **尝试**：一个能接触实际反馈、投入可控的动作；对象、场景与时间按当前条件确定。
- **观察**：什么支持、什么削弱、什么仍不能判断；安排适合场景的回看窗口。
- **边界**：哪些成本可以承担、何时停止；不撤销真实安全措施，不越过本人价值、他人同意或发送发布等授权。

演练和草稿可作为必要准备，但不能代替对外反馈。消息发送、表达被看见未必可撤回，不能为了“小实验”虚称可逆，也不自行发送。一次实验只检验一个有限预测，不拿他人当配合证明的工具。

### 两个虚构应用

**认识一个人。** 本人愿意且场景合适时，发出一次尊重边界的交流邀请。接受可削弱“任何尝试都会被拒绝”；明确拒绝就尊重并停止；未回复有多种解释，保留未知。一次拒绝不能证明自己整体不值得被喜欢，也不否认这次拒绝真实发生。

**开始事业。** 把“我还不够格”拆成这次尝试需要的具体能力。真实缺口先补；条件可行时，用一份有限成果接触合适的真实对象，提前定义观察问题。无人回应可能与触达有关，不能直接推导需求不存在；对方指出能力缺口则据此补足。学习是否保留，要看它对当前缺口的作用，不统一停掉学习。

## 回来后先改判断

预测被削弱，说明原来那条判断需要修正，不说明以后永不被拒绝。预测成真，更新技能、环境、对象、路线或应对，不说“你看，这也证明你成长了”来维护方法。信息不足就保留未知；重复试验需要新的信息价值，不能为了达标不断要求接触。

实验未做时，问清实际停在哪：步骤仍过大、现实有变化、不愿意，还是又被某个预测拦住。缩小、换路、补条件或停止都可选；未执行不等于假设成立，更不是人格失败。

记录只按宿主已有授权保留本人确认的发现、实际动作、反馈及当前判断，回到同一事项；不新建一套心理状态库，不把 AI 猜的核心信念固化进画像。是否减轻循环以本人体验和现实变化继续判断。

# 为什么我做 zpskill：一个陪伴你过好人生的人生搭子

作者：Zane · [项目](https://github.com/ZanePan2027/zpskill) · [第一次使用](life/first-task.md)

我做 zpskill，想让每个人都能拥有一个人生 AI 搭子，陪自己过好觉得值得的人生。

你可以给它起名字，告诉它怎样和你相处。从第一次认真听你说，到一起做选择、把事做成，再到记得共同经历、下次接着往前走，这段关系会随你们的生活一起生长。

“值得”不只指收入、效率和产出。一个下午晒太阳、休息、陪喜欢的人，没有可展示的成果，也可以值得。AI 给建议时，如果只围绕眼前的指标，就容易把一个局部答案当成人生答案。

「24小时重启人生」是你和搭子开始的第一天：一起认识过去、看清现在，选一个愿意开始的方向，并做出第一步。之后的日子，继续一起走。

所以这套 Skills 从你想过的生活出发，再看眼前的人、事和条件：现在要决定什么，有哪些路可以走，能先把哪一件事做出来。材料不够就问，不应该假装已经懂你。

## 理解之后，也要能一起做事

一次有用的帮助，可以是一份比较、一段沟通文字、一份简历，也可以是先把难受说清楚。日常用 `zp-life` 开始，它按任务选择方法；找工作有 `zp-career` 等专项入口。

你不需要先建立一整套系统。先解决眼前的问题；愿意长期使用时，再把确认过的背景、判断、成果和反馈留在自己的工作台。下次继续同一件事，现实变了，就改掉原来的建议。

## 没开始，不一定是你不够努力

有时缺的是真实能力或资源，需要准备；有时尚未试过，就已经替现实下了结论：“我不够格”“对方一定看不上我”。两种情况需要不同的帮助。

这次更新的 `zp-awaken` 会先分清事实和预测，再和你一起看依据。你愿意时，做一次有限尝试；发现缺口就补，信息不足就保留未知。它不会为了推动你行动，把休息、学习和工具建设一概说成逃避，也不把一次拒绝当成你的价值结论。

## 第一次，带一个问题就够

安装后可以这样说：

```text
使用 zp-life。我有一件想做却一直卡住的事：……。
这是我已经知道的条件：……。
先帮我弄清眼前要解决什么，再一起做出下一步用得上的东西。
```

搭子认真听你说，也会说出有根据的不同意见；一起做事，遇到新事实就一起改判断。你决定想过怎样的人生，它陪你把这段生活走下去。

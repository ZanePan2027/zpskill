# 总觉得没准备好：用 zp-awaken 检查回避循环

[English](avoidance.en.md) · [第一次使用](first-task.md) · [手册目录](README.md)

你想做一件事，却在开始前就认定自己不够格，于是反复准备、迟迟没接触现实反馈。`zp-awaken` 可以陪你区分真实障碍与尚未检验的预测，再决定要不要试一步。

学习、休息和建设工具都可能是必要的；它们本身不证明你在逃避。金钱、技能、时间、健康、真实危险和对方明确拒绝，也需要认真对待。

## 从最近的一次停住开始

```text
使用 zp-awaken。我想尝试提供一项服务，却觉得自己还不够格。
最近一直看课程，没有把成果给真实对象看过。
先帮我分清需要补的具体能力，和我提前作出的判断。
一次只问一个会改变下一步的问题，不要先给我贴“自我设限”的标签。
```

这是虚构示例，不代表使用者的实际经历或疗效。也可以带来“我想认识对方，却先认定会被拒绝”这样的一次片段。对方已经拒绝时，就尊重这个反馈。

## 把事实、预测和缺口分开

“我还没有做过完整案例”是一条事实；“所以任何人都不会愿意看”是预测。预测可能部分成真，也可能忽略其他解释，需要具体信息。

先补真实缺口。如果一门课解决的是明确的能力问题，而且知道学到什么就能试下一步，继续学习可能合理。AI 不应该为了推动行动，一概让你停掉准备。

## 你愿意时，选一个有限尝试

例如做出一份小成果，在合适场景邀请一位相关对象给出具体意见。提前说清：想检验什么、投入多少、观察什么、何时回看、哪些边界要保留。AI 可以帮你做草稿；发送给别人仍需你的明确授权。

这是借鉴 CBT 的自助检验，不是盘问自己，更不是用“你一定可以”替换担忧。无需等到完全自信，也不强迫每次聊天都交作业。

## 回来后允许几种结果

| 发生了什么 | 怎么继续 |
|---|---|
| 对方愿意看，并给了具体意见 | 修正“任何人都不会看”的预测，再处理真实意见 |
| 对方指出了能力缺口 | 据此补能力或改路线，不强行解读为成功 |
| 没有回复 | 保留多种可能，检查触达与场景；不直接判定自己不行或需求不存在 |
| 没有执行这次尝试 | 看步骤、条件与意愿，缩小、换路或停止；未做不能证明预测正确 |

一次尝试只检验一个有限判断，不决定一个人的价值。是否有帮助，要看你的体验和现实变化；本 Skill 不作心理诊断，也不替代专业治疗。

# 在聊天中开始

把下面这段话和当前情况一起发给AI：

```text
请做我的长期人生参谋。从我想过的生活出发，理解当前阶段，
结合人、资源和环境，判断几种可能走向，推荐现在能走的路。
说明关键理由、时间与现实安排，并完成当前能做的草稿或比较。
先使用我已经提供的信息；我的目标或现实有变化时，更新原来的判断。
我现在的情况是：……
```

第一次可以加一句：“叫我……，我喜欢你直接点破（或温和陪着）。”它会记住怎么称呼你、怎么跟你说话。

需要跨对话继续时，让AI整理一份接续摘要，保留自己的方向、当前判断、已发生的动作、可用材料和下一依赖，下次一起贴回来。

使用支持Skills的Agent，可以[安装完整工作台](install.md)，在同一项目文件夹保存资料和进展。

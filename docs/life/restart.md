# 24小时重启人生：和永生搭子开始的第一天

[English](restart.en.md) · [安装](install.md) · [先聊一件事](first-task.md) · [下次接着用](continue.md)

把今天作为重新开始的一天。让搭子认识你，陪你看清现在、想想未来，再一起开始一件你愿意做的事。之后的日子，你们继续根据现实反馈往前走。

## 先聊聊你

安装后，在支持 Skills 的 Agent 里说：

```text
使用 zp-life，做我的永生搭子，陪伴我过好人生。
我想和你用今天开始一次重启：先认识我，再一起看看下一步。
我会告诉你我的经历、现在的处境，以及我想过的生活。
请先听我说，沿着我提到的具体事情问；已有的信息直接用，不替我编经历。
```

你可以留出约两小时，用语音、聊天或已有资料讲讲自己；也可以分几次聊。先说最想说的部分，不必从出生开始写完整自传：哪些经历让你有劲、哪些一直放不下、现在的人和事怎样、想保留什么、想改变什么。

## 一起看清现在

让搭子把听到的东西还给你：你想过怎样的生活，现在有哪些条件、愿望和卡点。你看它有没有理解对；说错了就纠正，有些事还想不清也可以保留。

```text
说说你现在怎样理解我，尽量用我讲过的具体事情。
把我确认过的事实和你的理解分开，有不清楚的地方问我。
我们先挑一件我最想改变的事。
```

## 一起想几条路

围绕选中的那件事，看几种可走的方向：为什么适合你，需要什么，可能遇到什么，你想先试哪一条。未来可以从这里形成初稿，并在后来生活中不断修改。

## 今天就一起做一件事

把选中的方向落成一个现在用得上的成果或动作：一封准备好的消息、一份投递材料、一段腾出来的休息时间，或者一次愿意开始的尝试。需要等待别人的事，留下准备与下一步。

```text
我们就从这条路开始。请把今天能做的部分和我一起完成。
再保存我们确认过的背景、成果和停下的位置，明天接着走。
```

愿意时，给搭子起个名字，告诉它怎样称呼你、你喜欢怎样被陪，用 `zp-partner` 就能开始。需要长期记住时，在你选择并授权的文件夹建立工作台，具体见[下次接着用](continue.md)。

今天留下的是对你的初步理解、一条愿意走的路和已经开始的第一步。下一次，把真正发生的事带回来，让搭子陪你继续。

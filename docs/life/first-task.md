# 第一次用 zpskill：从一个问题得到可用成果

[English](first-task.en.md) · [安装与更新](install.md) · [手册目录](README.md)

zpskill 是 Zane 的「24小时重启人生」Skills，让 AI 成为你的人生搭子，陪伴你过好人生。第一次不需要先整理完人生、建立整套目录或学会所有指令；带来眼前的一件事就可以。

## 安装后，只说清这件事

尚未安装时，按[安装页](install.md)选择你的客户端。装好后新建对话，直接发送：

```text
使用 zp-life，做我的人生搭子，先陪我处理眼前这件事：
我在考虑是否换工作。现在收入稳定，但临时任务很多。
我希望保留收入，也想给家人和自己的创作留出时间。
先帮我判断还需要弄清什么，再把下一次沟通的提纲写出来。
没有的信息先问我，不要替我编经历或金额。
```

这是虚构使用示例，不是真人效果记录。你可以换成自己的处境：如何照顾身体、怎样安排一段休息、要不要接项目，或一封一直没写出的消息。只想有人听，也可以直接说“先听我说，不急着给建议”。

## 第一轮应该有什么

在这个例子里，有用的成果可以是一份沟通提纲：希望调整什么、能承担什么、需要问清什么、对方不同意时怎么接。缺少会改变判断的信息时，AI 应先问清；收入、合同和家庭条件不能猜。

不必一次得到完整人生规划。先看眼前的成果能不能用、有没有错认你的心意和事实。如果太泛，继续说：

```text
这些还太泛。请根据我已经说过的条件，把提纲写成我能直接带去沟通的版本。
不确定的地方单独问我。
```

草稿完成不等于事情已发生。发送、发布或代表你作承诺，需要你明确授权；你可以自己拿去用。

## 把真实反馈带回来

```text
接着刚才的事。对方同意减少临时任务，但还没有确定由谁接手。
请据此修改原来的建议和沟通提纲。
```

AI 应修改依赖新事实的判断。对方同意，是一个反馈；实际是否减少任务，还要看后续发生什么。

# 关于 Zane 与 zpskill

[项目首页](../README.md) · [开始重启人生](life/restart.md) · [English overview](../README.en.md)

Zane 是 zpskill 的作者。zpskill 是一套「24小时重启人生」Skills，让支持 Skills 的 AI Agent 成为你的**人生搭子，陪伴你过好人生**。

搭子先认识你想过的生活，再陪你做选择、完成眼前的事，并根据现实反馈一起成长。你可以给它起名字、告诉它怎样陪你；一起想、一起做，也一起经历生活里的开心与难处。

工作和事业、关系、身体、休息，以及你自己的愿望，都在这段陪伴里。什么样的人生值得，由你自己定义。共同经历、成果与反馈保存在你授权的工作台中，下次从真实停下的地方继续。

日常主入口是 `zp-life`；设定自己的搭子用 `zp-partner`；求职可以从 `zp-career` 开始；反复卡住或总在准备时，可以使用 `zp-awaken`。公开交付是方法、文档、模板与示例，使用条件见首页与教程。

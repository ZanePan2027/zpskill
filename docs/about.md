# 关于 Zane 与 zpskill

[项目首页](../README.md) · [第一次使用](life/first-task.md) · [English overview](../README.en.md)

Zane 是 zpskill 的作者。zpskill 是一套人生经营 Skills，让支持 Skills 的 AI Agent 从使用者想过的生活出发，提供长期人生参谋与具体任务帮助。

**先认识你想过的生活，再陪你把眼前的事做成，不辜负。**

这里的“人生经营”包含工作和事业，也包含关系、身体、休息与真实生活。什么样的人生值得，由使用者自己定义。工作台用来接续背景、成果与反馈；它服务于眼前的生活，不以建系统本身为目标。

日常主入口是 `zp-life`；求职可以从 `zp-career` 开始；反复卡住、提前否定自己或总在准备时，可以使用 `zp-awaken`。项目的公开内容是方法、文档、模板与示例，具体能力和使用条件见首页与教程。
